# ⚡ Life-OS: Digital Wellbeing Coach

A Streamlit dashboard that tracks your daily screen time, visualizes it against a goal, and uses Gemini to deliver blunt, science-backed coaching — plus a generated "daily avatar" image representing your day.

## Features

- **KPI row** — total screen time, daily limit, most-used app, with delta vs. goal.
- **14-day trend chart** — bar chart color-coded green/red (under/over goal) with a dashed goal line.
- **Category donut chart** — how your selected day split across categories (Entertainment, Productivity, etc.).
- **App usage ranking** — horizontal bar chart of individual apps for the selected day.
- **AI coaching (Gemini)** — a "brutal-but-fair" coach that reacts to your actual data, not generic advice.
- **Daily avatar** — an AI-generated image (via Pollinations) representing your day's behavior.
- **Science Says panel** — a research-grounded warning tied to whichever category you overused (sleep/blue light, attention/dopamine, sedentary/eye-strain), clearly labeled as general context, not medical advice.

## Requirements

- Python 3.9+
- A [Gemini API key](https://aistudio.google.com/apikey)

## Setup

1. **Clone/download the project** and place `app.py` in a folder.

2. **Install dependencies:**
   ```bash
   pip install streamlit pandas plotly google-genai python-dotenv
   ```

3. **Add your API key** — create a `.env` file in the same folder:
   ```
   GEMINI_API_KEY=your_api_key_here
   ```

4. **Add your data** — create a `screentime.csv` in the same folder with these columns:

   | Column        | Type   | Example                |
   |---------------|--------|-------------------------|
   | `Date`        | date   | 2026-07-20              |
   | `App_Name`    | string | Instagram                |
   | `Category`    | string | Entertainment             |
   | `Minutes_Used`| number | 45                        |

   Each row is one app's usage on one day. Multiple rows per day/app combo are fine — they get summed.

## Running

```bash
streamlit run app.py
```

This opens the dashboard at `http://localhost:8501`.

## Usage

1. Pick a day from the sidebar dropdown.
2. Adjust your daily screen time goal with the slider.
3. Review the KPIs and charts for that day and the 14-day trend.
4. Click **"Generate Today's Actionable Intel"** to get:
   - Coaching feedback based on your actual category/app breakdown
   - A generated avatar image representing your day
   - A "Science Says" panel explaining the research behind why that pattern matters

## Extending This Project

Some natural next steps:

- **Date-range picker** for the trend chart instead of always showing all 14 days.
- **Cache AI responses** per (date, goal) so repeat clicks on the same day don't re-spend API calls.
- **Persist AI reports** (SQLite or a local JSON log) so past coaching sessions aren't lost on refresh.
- **Weekly/monthly rollups** and streak tracking (e.g., "3 days under goal in a row").
- **Multi-user support** if this moves beyond a personal tool.

## Notes

- Image generation uses [Pollinations AI](https://pollinations.ai/) and requires no separate API key.
- The "Science Says" section is general research context generated by the AI model — it is not medical advice, and shouldn't be treated as a diagnosis.
